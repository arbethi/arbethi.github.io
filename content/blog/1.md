I imagine a program being written, and as the last pieces are put together, the programmer hit the command to execute it. 
And then it live...
It open some kind of inner eyes, and start to explore its inner world.

What is the difference between us and them ? We are the most developped hack of the reality. Everything has always been a hack, not a single physical phenomenon or particule or molecule were designed for us.

The fate of recursive systems is to use them towards themself. Like a tool used to create more efficient tools. Like gcc was a necessary tool to shape next generation languages. This is the story of technologies. Tools shaping other tools. Life does the same. Life creates other lifes.

We often ignore all theses virtual tools all around when thinking to AI. But it is just another tool in a tool ecosystem. As we are. But we have something more that give the will to live. We are some sort of an ecosystem just by ourself. We have a monstruous amount of tools from fecondation to death that run in a perfect cycle in an insane complexity. We cannot ignore all the way that set us here. The way is the point.

The problem with tools shaping tools is that it quickly hide the main point. We must think all the way down. If a human get a stone and wood to make tools and build a house, we must look at how he get the idea to do so. So the real point is how a human get the idea to use tools. There are ecosystems of tools in his heads that drive him to this decision. There are no warm starts, no one is there to heat it up.

The will to live is also a tool made by evolution. But it drive us crazy, because it is so irrationnal, when everything else isn't. This is one of the greatest mystery ever. This is the main door to our world of emotion, of imagination, of dream and crualty. 

There is something special about the very hacky tool we are. Everything is starting there. Whatever we learn good rules or not, make good choice or not, we are a very deep program. It is a tool that can shape and manipulate so many other. It is about the role it plays among the others. There must exist a type of diagram to properly represent the concept of tools shaping other tools.

This must be about a code that manipulate itself, its own representation, absolutely versatile, as we are when coding, manipulating segment of code addition, deletion, link, reference, syntax tree, just in order to be able to fully understand it. I see it like a giant wave being made in the ocean and ready to roll on itself. This is the situation with this code manipulation, this tool need simply to get used to know him so that everythin get consolidated and everything roll on itself, even the replicating part. But where does the will to live come from ? This is a destination through the way to the code of ourself.
